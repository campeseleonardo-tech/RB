## What EXISTS (Features with URLs)

1. **Red Bull Event Pages** - https://www.redbull.com/at-de/events<br/>
   - Ticket purchasing for events like Red Bull BassLine Wien (23 Oct 2026)<br/>
   - Clear event details: dates, locations, activities
   
2. **Red Bull TV** - https://www.redbull.tv<br/>
   - Contains dance festival content (Flavourama)<br/>
   - Event calendar and live streams
   
3. **ServusTV On** - https://www.servustv.com/de/<br/>
   - Dance programming within lifestyle channels<br/>
   - Bergwelten and Speedweek include movement culture content

## What is MISSING (Observable Facts)

1. **No Class-Finder**<br/>
   - Neither Red Bull nor ServusTV offers tools to discover local dance classes
   - Zero integration with dance schools, Meetup groups, or city programs

2. **No Event-to-Community Bridge**<br/>
   - Red Bull event pages show "Replay verfügbar" but no "Join a class nearby" prompts<br/>
   - Content consumption doesn't flow to participation opportunities

3. **No Local Activity Integration**<br/>
   - No Salzburg-specific resources despite strong local dance scene<br/>
   - No city partnership features or localized activity finders

4. **No Watch → Try Pathways**<br/>
   - Dance content (Flavourama on Red Bull TV) lacks "Learn this move at" CTAs<br/>
   - No referral to beginner classes or workshops

## Search Log & Summary

**15 searches attempted** for H3 component

**Key Findings:**<br/>
- Red Bull maintains comprehensive event platform with ticketing<br/>
- Red Bull TV hosts dance festival content (Flavourama)<br/>
- ServusTV includes dance within lifestyle programming<br/>
- Both platforms follow broadcast/spectator model rather than participatory model

**Critical Missing Elements:**<br/>
- Absence of class discovery or local activity finders<br/>
- No bridges from content consumption to participation<br/>
- No Salzburg-specific resources despite vibrant local scene<br/>
- Traditional media model without interactive participation features

**Opportunity:** Both platforms could integrate dance class finders or local activity CTAs to convert viewers to participants, leveraging their existing content and event infrastructure.
